# Finance-test

재무제표를 가져와 분석하고 대시보드로 보여주는 단일 HTML 도구 (드래프트).

`index.html`을 브라우저에서 열면 바로 동작합니다. 빌드 과정은 없고, 라이브러리는 cdnjs에서 불러옵니다.

## 흐름

1. **가져오기**
   - 파일: `.xlsx` `.xls` `.csv` (SheetJS), `.pdf` (pdf.js 텍스트 추출), `.docx` (mammoth), `.html`, `.txt`
   - 텍스트 붙여넣기 (스프레드시트 복사본, 공시 본문 등)
   - 웹페이지 URL: 페이지 안의 `<table>`을 읽습니다. 대부분의 사이트는 CORS 때문에 프록시가 필요합니다.
   - DART OpenAPI: `fnlttSinglAcntAll` (인증키 + 8자리 고유번호)
   - 샘플 데이터
   - **AI로 항목 추출**: 규칙 기반 파서가 놓친 경우(스캔 PDF 등) 원문이나 PDF를 Claude에 보내 구조화된 JSON으로 추출합니다.
2. **항목 확인·수정**: 자동 인식된 22개 표준 계정(손익·재무상태·현금흐름)을 표에서 바로 고칠 수 있습니다.
3. **분석 결과**
   - KPI 카드, 건전성 점수(성장성·수익성·안정성·활동성·현금흐름)
   - 차트: 손익 추이, 마진율, 자본 구조, 현금흐름
   - 재무비율 19종 + 양호/보통/주의 평가, 규칙 기반 주요 포인트
   - **AI 분석 리포트** (Claude, 스트리밍)
   - JSON / CSV 저장, 인쇄(PDF)

## AI 설정

1단계 하단 “AI 설정”에 Anthropic API 키를 넣습니다. 기본 모델은 `claude-opus-5-5`입니다.
키는 브라우저에서 `api.anthropic.com`으로 직접 전송되므로(`anthropic-dangerous-direct-browser-access`), 개인용 드래프트로만 쓰고 공개 서비스로 만들 때는 서버 측 호출로 바꿔야 합니다.

## 한계 (드래프트)

- 규칙 기반 파서는 계정명 동의어 매칭이라 복잡한 표(분기 3개월/누적 병합 헤더 등)는 놓칠 수 있습니다 → 2단계에서 수정하거나 AI 추출 사용.
- 평가 기준은 업종 무관 일반 참고치입니다.
- DART 고유번호 검색(corpCode.xml)은 아직 없습니다.
